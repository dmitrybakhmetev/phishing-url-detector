# 🛡️ Phishing URL Detector

Консольный инструмент на Python для автоматического анализа URL и выявления потенциальных признаков **фишинга и социальной инженерии**.

Программа не открывает ссылки, а анализирует их структуру с помощью набора эвристических правил и рассчитывает итоговый уровень риска.

---

## 🔍 Как работает

Детектор проверяет URL по нескольким критериям:

| Эвристика                      | Баллы |
| ------------------------------ | ----: |
| HTTP вместо HTTPS              |    +3 |
| Использование IP-адреса        |    +5 |
| Длинный домен (>45 символов)   |    +3 |
| Маскировка под известный бренд |    +5 |
| Подозрительный TLD             |    +5 |
| Избыток поддоменов             |    +3 |
| Сдвоенные дефисы (`--`)        |    +3 |

После анализа все баллы суммируются и определяется уровень риска.

### 📊 Уровни риска

* 🟢 **LOW (0–2)** — подозрительных признаков практически нет.
* 🟡 **MEDIUM (3–6)** — URL вызывает подозрения, рекомендуется соблюдать осторожность.
* 🔴 **HIGH (7+)** — высокая вероятность фишинга. Переход по ссылке не рекомендуется.

---

## 💻 Примеры использования

Детектор можно использовать непосредственно в Python:

```python
from detector import analyze_url

result = analyze_url("https://example.com")

print(result)
```

Пример результата:

```text
URL: https://example.com
Risk level: LOW
Risk score: 0
```

### Подозрительный URL

```python
from detector import analyze_url

result = analyze_url("http://192.168.1.100/login")

print(result)
```

Возможный результат:

```text
URL: http://192.168.1.100/login
Risk level: HIGH
Risk score: 8
```

В данном случае обнаружены сразу несколько признаков: использование `HTTP` и IP-адреса.

## 🚀 Запуск

### Требования

* Python **3.6+**
* Дополнительные библиотеки не требуются.

Используются только стандартные модули Python: `urllib` и `re`.

### Запуск тестов

```bash
python test_detector.py
```

После запуска программа проверит подготовленные URL и выведет результаты анализа.
